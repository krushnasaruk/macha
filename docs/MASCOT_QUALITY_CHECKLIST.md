# CaféOS Mascot Quality Control & Art Direction Checklist

Every mascot illustration, sheet panel, and interactive asset must pass this 4-tier quality assurance checklist before being committed to the production library.

---

## Tier 1: Face & Facial Communication Checklist

| Check Item | Requirement | Pass Criteria |
| :--- | :--- | :---: |
| **F1. Identity Match** | Face structure matches the master character reference. | [ ] |
| **F2. Tan Patch Integrity** | Distinctive tan markings (`#D2B18E`) surround both eyes cleanly without generic human eyebrows. | [ ] |
| **F3. Eye Gaze Vector** | Gaze direction is intentional (forward at user, toward held object, or upward in thought). | [ ] |
| **F4. Eyelid State** | Eyelids communicate alertness or relaxation appropriately (not static dots for all moods). | [ ] |
| **F5. Muzzle Shape** | Cream muzzle (`#EEE0CF`) retains soft, rounded oval form anchored under the eyes. | [ ] |
| **F6. Nose Placement** | Black oval nose (`#171615`) sits centered at the top-midline of the muzzle. | [ ] |
| **F7. Mouth Expression** | Subtle, organic mouth curvature; no oversized, distorted human grins. | [ ] |
| **F8. Head Direction** | Head tilt (subtle roll, nod, or turn) reinforces the emotional posture. | [ ] |

---

## Tier 2: Paw & Anatomy Checklist

| Check Item | Requirement | Pass Criteria |
| :--- | :--- | :---: |
| **P1. Bear Anatomy** | Form reflects rounded bear paws with 3 padded digits + 1 thumb pad, never human fingers. | [ ] |
| **P2. Continuous Lineage** | Arm connects seamlessly from torso shoulder to wrist with clean 3-4px black outline. | [ ] |
| **P3. Wrist Angle** | Wrist bend conforms to natural bone-joint angles (no broken 90° bends or twisting). | [ ] |
| **P4. Digit Count** | Zero extra, deformed, or missing digits. | [ ] |
| **P5. Palm Definition** | When palm is visible, soft inner paw pad contour is drawn with correct perspective. | [ ] |
| **P6. Arm Thickness** | Forearms maintain consistent charcoal fur volume without sudden tapering or bulging. | [ ] |

---

## Tier 3: Object Interaction & Physics Checklist

| Check Item | Requirement | Pass Criteria |
| :--- | :--- | :---: |
| **O1. Physical Occlusion** | Paw digits wrap around the front of the object while the palm/arm stays behind it. | [ ] |
| **O2. Definite Grip** | Object is visibly clutched, cradled, or pressed; zero floating or detached props. | [ ] |
| **O3. Handle Realism** | Handles (cups, pans, pots, spatulas) are threaded through the curled paw grip. | [ ] |
| **O4. Balance & Gravity** | Object weight aligns with the bear's stance and shoulder inclination. | [ ] |
| **O5. Proportional Scale** | Object size is scaled realistically relative to a sturdy café chef bear. | [ ] |
| **O6. Depth & Outline** | Clean outlines separate object edges from fur and apron contours. | [ ] |

---

## Tier 4: Overall Brand Consistency Checklist

| Check Item | Requirement | Pass Criteria |
| :--- | :--- | :---: |
| **B1. Color Fidelity** | Strict adherence to the official palette (Fur `#393635`, Tan `#D2B18E`, Muzzle `#EEE0CF`, Apron `#F4EFE6`). | [ ] |
| **B2. Flat 2D Styling** | Clean sticker-like flat cartoon illustration with zero 3D plastic shading or realism. | [ ] |
| **B3. Uniform Outlines** | Smooth, continuous black outlines (`#171615`) with consistent stroke weight. | [ ] |
| **B4. Alpha Channel** | High-resolution PNG with clean transparent background and zero fringing. | [ ] |
| **B5. Leg & Stance Stasis** | Torso, apron, and sturdy short legs maintain accurate head-to-body scale ratio (1:1.6). | [ ] |
